================================================================================
                        COMPONENTE TOOLTIP REUTILIZABLE
================================================================================

A continuación tienes el código para implementar un Tooltip reutilizable 
que cumple con el sistema de diseño actual del proyecto Expendio. Este 
componente ayudará a solucionar la heurística de "Ayuda y documentación".

--------------------------------------------------------------------------------
PASO 1: CREAR EL COMPONENTE
--------------------------------------------------------------------------------
Crea un nuevo archivo llamado `Tooltip.jsx` en la ruta:
`src/components/ui/Tooltip.jsx`

Y pega el siguiente código:

import { useState } from 'react';

export function Tooltip({ children, text, position = 'top' }) {
  const [isVisible, setIsVisible] = useState(false);

  return (
    <div 
      className="tooltip-container"
      onMouseEnter={() => setIsVisible(true)}
      onMouseLeave={() => setIsVisible(false)}
      onFocus={() => setIsVisible(true)}
      onBlur={() => setIsVisible(false)}
    >
      {children}
      
      {isVisible && (
        <div className={`tooltip-box tooltip-${position}`}>
          {text}
        </div>
      )}
    </div>
  );
}

--------------------------------------------------------------------------------
EJEMPLO DE USO EN TUS PÁGINAS
--------------------------------------------------------------------------------
Para utilizarlo en cualquier lugar de tu proyecto (como en tu Dashboard o POS),
solo debes importarlo y envolver el elemento deseado:

import { Tooltip } from '../components/ui/Tooltip';
import { HelpCircle } from 'lucide-react';

// En el render:
<Tooltip text="Ingresa el nombre completo del proveedor" position="top">
  <HelpCircle size={14} className="text-muted" />
</Tooltip>

// O en un botón:
<Tooltip text="Agrega este producto al carrito" position="bottom">
  <button className="btn btn-primary">Agregar</button>
</Tooltip>
